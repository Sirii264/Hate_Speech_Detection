# Hate_Speech_Detection
This project is a Hate Speech Detection System built using Python and Machine Learning. It automatically classifies text into different categories such as Hate Speech, Offensive Language, or Neither. The model is trained on a labeled Twitter dataset and uses Natural Language Processing (NLP) techniques to preprocess text before making predictions.
Features
Detects hate speech in text.
Cleans and preprocesses text using NLP techniques.
Removes stop words, punctuation, URLs, and special characters.
Converts text into numerical features using TF-IDF.
Trains a machine learning classifier for accurate predictions.
Predicts the category of new user-entered text.
