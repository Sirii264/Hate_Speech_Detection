# Hate Speech Detection

## Overview
This project detects hate speech in text using Machine Learning and Natural Language Processing (NLP). It classifies text into Hate Speech, Offensive Language, or Neither.

## Technologies Used
- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- TF-IDF Vectorizer
- Jupyter Notebook

## Features
- Text preprocessing
- Stopword removal
- TF-IDF vectorization
- Machine Learning classification
- Predicts user-entered text

## Dataset
Twitter Hate Speech Dataset

## Project Structure
├── Hate_Speech_Detection.ipynb
├── twitter.csv
├── README.md

## Results
Model Accuracy: 87.71%
